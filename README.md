# Hoja de incidencias · Escuela 26-27

App móvil (instalable) para que cada responsable apunte las incidencias mensuales de sus monitores. Los datos se guardan en la hoja de Google del registro mes a mes.

- **App:** https://mikelop1991.github.io/HojaIncidencias/
- **Conexión con la hoja:** pegar la URL `/exec` de Apps Script en `config.js`.
- **Backend:** carpeta `apps-script/` (Code.gs + Index.html), se pega en Extensiones → Apps Script de la hoja.
- Guía completa: [GUIA.md](GUIA.md)
